Core Capabilities

專門解決學校借用排程痛點的三大引擎

1. 資訊設備借用查詢

隨時隨地查看今天或明天有誰借用了 iPad 行動學習車、Chromebook、教師筆電、投影機或 4K 相機。清楚列出借用人、使用節次與借用狀態，避免課堂上設備衝突！

💡 支援指令與語意：
• #查設備
• #設備 平板車
• 今天下午有空檔的相機嗎？

2. 校園場地借用查詢

電腦教室(一/二)、創客自造教室、第一會議室、階梯視聽教室、室內體育館排程全天候線上掌握。支援指定教室時段空檔查詢，提醒開鎖與冷氣管理規範。

💡 支援指令與語意：
• #查場地
• #場地 電腦教室
• 明天第一會議室第7節有人借嗎？

3. 個人學期借用統計

全台首創！老師輸入姓名即可調閱本學期個人借用累計次數、品項借用頻率排行（如：iPad 車 12次、電腦教室 8次）及最近借用足跡，期末填寫教學成果報告超省力！

💡 支援指令與語意：
• #查個人 陳乃誠
• #我的借用 林志強
• 我這學期總共借了幾次平板車？
每日定時同步機制 (Daily Auto-Sync)

免手動抄寫！直接橋接學校官方借用 API

透過 Google Apps Script 的「時間驅動觸發器 (Time-driven Trigger)」，系統每天早上 07:00 自動呼叫學校系統 API 抓取當日與近期借用名冊，寫入 Google 試算表快取，毫秒級回應老師提問，更免去學校主機被頻繁打爆的困擾！

// 支援各種學校 API 格式
GET https://your-school.edu.tw/api/bookings?date=2026-09-10
✓ 自動去重比對 (Composite Key)
✓ 離線時自動回退至 Google 試算表
✓ 支援 LINE 手動輸入「#同步」強制刷新

Deployment Steps

四步驟完成校園 LINE 借用小幫手架設

1

建立試算表貼上程式碼

新建 Google 試算表，點擊選單「擴充功能」➔「Apps Script」，將上方生成的 Code.gs 貼上並儲存。

2

執行一鍵初始化

在 Apps Script 函式下拉選單中選擇 initBookingSystemSheet 並點擊「執行」，自動為試算表建立借用總表、設備清單與示範資料！

3

部署為網頁並綁定 Webhook

點擊「部署」➔「新增部署作業」，類型選擇「網頁應用程式」，存取權選「所有人」，複製產出的網址貼至 LINE Developers 後台的 Webhook URL。

4

設定每日定時同步排程

在 Apps Script 左側點擊鬧鐘圖示「觸發條件」，新增一個「時間驅動」觸發器，指定每天早上 07:00 執行 dailySyncBookingApi 即可自動同步！
